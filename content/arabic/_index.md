# GroupDocs.Merger document merging API – دليل كامل للدمج والتقسيم

## إجابات سريعة
- **ما الذي يفعله الـ API؟** يقوم بدمج، تقسيم، إعادة ترتيب، وتأمين المستندات عبر أكثر من 50 تنسيقًا.  
- **ما المنصات المدعومة؟** .NET (Standard, Framework, Core, Mono) and Java (J2SE 7‑10).  
- **هل أحتاج إلى برنامج خارجي؟** لا—لا توجد تبعيات لـ Microsoft Office أو Adobe.  
- **هل يمكنني حماية المستندات؟** نعم، يمكنك إضافة أو إزالة أو تحديث كلمات المرور والأذونات.  
- **هل هناك حد لحجم الملف؟** تم تحسين الـ API للملفات الكبيرة وعمليات الدفعات.  

## ما هو GroupDocs.Merger document merging API؟
حمّل ملفاتك واستدعِ طرق الدمج أو التقسيم المناسبة – هذا هو سير العمل الأساسي لـ GroupDocs.Merger document merging API. يوفر واجهة واحدة ومتسقة للتعامل مع ملفات PDF، ومستندات Office، والصور، والأرشيفات، وأكثر، مع الحفاظ على التخطيط والبيانات الوصفية وإعدادات الأمان.

GroupDocs.Merger document merging API هي مكتبة موجهة للمطورين تُجرد تعقيد التعامل مع صيغ المستندات المتعددة. تتيح لك دمج الملفات برمجياً، تقسيمها حسب الصفحات أو النطاقات، وتطبيق عمليات متقدمة على الصفحات—كل ذلك مع الحفاظ على التخطيط الأصلي والبيانات الوصفية.

## لماذا تختار GroupDocs.Merger document merging API؟
تحصل على توافق عبر المنصات، دعم واسع للصيغ، عدم وجود تبعيات خارجية، أداء عالي، وأمان مدمج—كل ذلك في حزمة واحدة. يقوم الـ API ببث البيانات، لذا حتى الملفات متعددة الجيجابايت تُعالج بأقل استهلاك للذاكرة، مما يجعله مثالياً للمهام الدفعية على الخادم.

## حوّل طريقة إدارة المستندات عبر منصات متعددة
يوفر GroupDocs.Merger حلاً قويًا وعبر‑المنصات لمعالجة المستندات يُبسّط طريقة عمل المطورين مع الملفات في تطبيقاتهم. يتيح الـ API الشامل لك دمج مستندات متعددة في ملف واحد، تقسيم المستندات إلى مكونات أصغر، إعادة ترتيب الصفحات، تطبيق خيارات الأمان، وأكثر—كل ذلك بأقل قدر من الشيفرة وأقصى كفاءة.

سواءً كنت تطوّر في بيئات .NET أو Java، يقدم GroupDocs.Merger قدرات معالجة مستندات عالية الأداء ومتسقة تعمل بسلاسة مع أكثر من 50 صيغة ملف شائعة بما في ذلك PDF، ومستندات Office، والصور، وأكثر.

## الميزات الرئيسية والقدرات
- **دمج مستندات شامل** – دمج مستندات كاملة أو صفحات محددة من مصادر متعددة في ملف موحد واحد.  
- **دعم صيغ متعددة** – دمج صيغ ملفات مختلفة في مستند موحد (مثال: DOC، XLSX، والصور في ملف PDF واحد).  
- **تقسيم مستندات ذكي** – تقسيم المستندات حسب أرقام الصفحات، النطاقات، أو استخراج صفحات محددة كملفات منفصلة.  
- **عمليات صفحات متقدمة** – نقل، إزالة، تدوير، تبديل، واستخراج الصفحات بدقة تحكم.  
- **إدارة الأمان** – إضافة، إزالة، أو تحديث كلمات مرور المستندات والأذونات.  
- **دعم كائنات OLE** – إدراج المستندات ككائنات OLE داخل ملفات Word، Excel، PowerPoint، وVisio.  
- **بدون تبعيات خارجية** – معالجة المستندات دون الحاجة إلى Microsoft Office أو برامج Adobe.  
- **أداء عالي** – مُحسّن لمعالجة المستندات الكبيرة وعمليات الدفعات بكفاءة.

## صيغ الملفات المدعومة
يعمل GroupDocs.Merger مع أكثر من 50 صيغة ملف عبر فئات متعددة:

- **المستندات**: PDF, DOC, DOCX, RTF, ODT, XPS, EPUB, HTML  
- **جداول البيانات**: XLS, XLSX, XLSM, XLSB, ODS, CSV, TSV  
- **العروض التقديمية**: PPT, PPTX, PPS, PPSX, ODP  
- **الصور**: JPG, PNG, BMP, GIF, TIFF, SVG  
- **المخططات**: VSDX, VSDM, VSSX, VSTX, VDX, VSX, VTX  
- **الأرشيفات**: ZIP, TAR, 7Z  
- **وغيرها الكثير**
