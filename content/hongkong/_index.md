# GroupDocs.Merger 文件合併 API – 完整合併與分割指南

The **GroupDocs.Merger 文件合併 API** gives you a fast, cross‑platform way to combine, split, and manipulate a wide range of document types directly from your .NET or Java applications. Whether you need to merge several PDFs into a single report, split a large contract into individual pages, or reorder slides in a presentation, this API handles it with just a few lines of code.

## Quick Answers
- **API 的功能是什麼？** It merges, splits, reorders, and secures documents across 50+ formats.  
- **支援哪些平台？** .NET (Standard, Framework, Core, Mono) and Java (J2SE 7‑10).  
- **需要外部軟件嗎？** No—no Microsoft Office or Adobe dependencies.  
- **可以保護文件嗎？** Yes, you can add, remove, or update passwords and permissions.  
- **檔案大小有上限嗎？** The API is optimized for large files and batch operations.  

## What is GroupDocs.Merger document merging API?

Load your files and call the appropriate merge or split methods – that’s the core workflow of the GroupDocs.Merger document merging API. It provides a single, consistent interface for handling PDFs, Office documents, images, archives, and more, while preserving layout, metadata, and security settings.

The GroupDocs.Merger document merging API is a developer‑focused library that abstracts the complexity of handling multiple document formats. It lets you programmatically merge files, split them by pages or ranges, and apply advanced page operations—all while preserving the original layout and metadata.

## Why choose GroupDocs.Merger document merging API?

You get cross‑platform consistency, broad format support, no external dependencies, high performance, and built‑in security—all in one package. The API streams data, so even multi‑gigabyte files are processed with a low memory footprint, making it ideal for server‑side batch jobs.

## Transform how you manage documents across multiple platforms

GroupDocs.Merger provides a powerful, cross‑platform solution for document manipulation that streamlines how developers work with files in their applications. Our comprehensive API enables you to merge multiple documents into one, split documents into smaller components, reorder pages, apply security options, and much more—all with minimal code and maximum efficiency.

Whether you're developing in .NET or Java environments, GroupDocs.Merger delivers consistent, high‑performance document processing capabilities that work seamlessly with 50+ popular file formats including PDF, Office documents, images, and more.

## Key features & capabilities
- **完整的文件合併** – Combine entire documents or specific pages from multiple sources into a single cohesive file.  
- **跨格式支援** – Merge different file formats into a unified document (e.g., DOC, XLSX, and images into a single PDF).  
- **智慧文件分割** – Divide documents by page numbers, ranges, or extract specific pages as separate files.  
- **進階頁面操作** – Move, remove, rotate, swap, and extract pages with precise control.  
- **安全管理** – Add, remove, or update document passwords and permissions.  
- **OLE 物件支援** – Insert documents as OLE objects within Word, Excel, PowerPoint, and Visio files.  
- **無外部依賴** – Process documents without requiring Microsoft Office or Adobe software.  
- **高效能** – Optimized for processing large documents and batch operations efficiently.

## Supported file formats
GroupDocs.Merger supports over 50 file formats across multiple categories:

- **文件**: PDF, DOC, DOCX, RTF, ODT, XPS, EPUB, HTML  
- **試算表**: XLS, XLSX, XLSM, XLSB, ODS, CSV, TSV  
- **簡報**: PPT, PPTX, PPS, PPSX, ODP  
- **影像**: JPG, PNG, BMP, GIF, TIFF, SVG  
- **圖表**: VSDX, VSDM, VSSX, VSTX, VDX, VSX, VTX  
- **壓縮檔**: ZIP, TAR, 7Z

## Frequently asked questions

**Q: 我可以在商業產品中使用此 API 嗎？**  
A: 是的，只要擁有有效的 GroupDocs 授權。可提供免費試用以供評估。

**Q: 此 API 支援受密碼保護的 PDF 嗎？**  
A: 當然支援。您可以使用相同的 API 呼叫開啟、修改並重新加密受保護的 PDF。

**Q: 相容的 .NET 與 Java 版本有哪些？**  
A: 支援 .NET Standard 2.0、.NET Framework 2.0 以上、.NET Core 2.0 以上、Mono 1.2 以上；Java 7、8 以及 10 以上皆完整相容。

**Q: API 如何處理極大型檔案？**  
A: 它以串流方式處理資料，並使用記憶體效能演算法，讓您在不耗盡系統資源的情況下處理多 GB 的文件。

**Q: 是否內建 OCR 或文字抽取支援？**  
A: 雖然核心合併 API 主要針對結構操作，但您可結合 GroupDocs.Parser 以滿足進階文字抽取與 OCR 需求。

**Q: 如何快速上手？**  
A: 安裝 NuGet 套件 (`GroupDocs.Merger`)（.NET）或加入 Maven 依賴（Java），然後依照「文件載入」教學載入第一個檔案。

**Q: 我可以將不同檔案類型合併成單一 PDF 嗎？**  
A: 可以——API 能將 PDF、Word、Excel、影像及其他多種格式合併為單一 PDF 輸出。
