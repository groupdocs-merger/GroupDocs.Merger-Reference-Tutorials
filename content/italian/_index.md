# GroupDocs.Merger document merging API – guida completa alla fusione e divisione

The **GroupDocs.Merger document merging API** gives you a fast, cross‑platform way to combine, split, and manipulate a wide range of document types directly from your .NET or Java applications. Whether you need to merge several PDFs into a single report, split a large contract into individual pages, or reorder slides in a presentation, this API handles it with just a few lines of code.

## Risposte rapide
- **Cosa fa l'API?** Unisce, divide, riordina e protegge i documenti in oltre 50 formati.  
- **Quali piattaforme sono supportate?** .NET (Standard, Framework, Core, Mono) e Java (J2SE 7‑10).  
- **Ho bisogno di software esterno?** No—nessuna dipendenza da Microsoft Office o Adobe.  
- **Posso proteggere i documenti?** Sì, è possibile aggiungere, rimuovere o aggiornare password e autorizzazioni.  
- **C'è un limite di dimensione del file?** L'API è ottimizzata per file di grandi dimensioni e operazioni batch.  

## Cos'è l'API di fusione documenti GroupDocs.Merger?
Carica i tuoi file e chiama i metodi di unione o divisione appropriati – questo è il flusso di lavoro principale dell'API di fusione documenti GroupDocs.Merger. Fornisce un'interfaccia unica e coerente per gestire PDF, documenti Office, immagini, archivi e altro, preservando layout, metadati e impostazioni di sicurezza.

L'API di fusione documenti GroupDocs.Merger è una libreria orientata agli sviluppatori che astrae la complessità della gestione di più formati di documento. Consente di unire programmaticamente i file, dividerli per pagine o intervalli e applicare operazioni avanzate sulle pagine—tutto preservando il layout originale e i metadati.

## Perché scegliere l'API di fusione documenti GroupDocs.Merger?
Ottieni coerenza cross‑platform, ampio supporto di formati, nessuna dipendenza esterna, alte prestazioni e sicurezza integrata—tutto in un unico pacchetto. L'API trasmette i dati in streaming, così anche i file multi‑gigabyte vengono elaborati con un basso consumo di memoria, rendendola ideale per processi batch lato server.

## Trasforma il modo in cui gestisci i documenti su più piattaforme
GroupDocs.Merger fornisce una soluzione potente e cross‑platform per la manipolazione dei documenti che semplifica il modo in cui gli sviluppatori lavorano con i file nelle loro applicazioni. La nostra API completa consente di unire più documenti in uno, dividere i documenti in componenti più piccoli, riordinare le pagine, applicare opzioni di sicurezza e molto altro—tutto con codice minimo e massima efficienza.

Che tu stia sviluppando in ambienti .NET o Java, GroupDocs.Merger offre capacità di elaborazione documenti coerenti e ad alte prestazioni che funzionano senza problemi con oltre 50 formati di file popolari, tra cui PDF, documenti Office, immagini e altro.

## Caratteristiche principali e capacità
- **Unione completa di documenti** – Combina interi documenti o pagine specifiche da più sorgenti in un unico file coerente.  
- **Supporto cross‑format** – Unisce diversi formati di file in un documento unico (ad es., DOC, XLSX e immagini in un unico PDF).  
- **Divisione intelligente dei documenti** – Divide i documenti per numeri di pagina, intervalli o estrae pagine specifiche come file separati.  
- **Operazioni avanzate sulle pagine** – Sposta, rimuove, ruota, scambia ed estrae pagine con controllo preciso.  
- **Gestione della sicurezza** – Aggiunge, rimuove o aggiorna password e autorizzazioni dei documenti.  
- **Supporto oggetti OLE** – Inserisce documenti come oggetti OLE all'interno di file Word, Excel, PowerPoint e Visio.  
- **Nessuna dipendenza esterna** – Processa i documenti senza richiedere software Microsoft Office o Adobe.  
- **Alte prestazioni** – Ottimizzato per elaborare grandi documenti e operazioni batch in modo efficiente.

## Formati di file supportati
GroupDocs.Merger funziona con oltre 50 formati di file in diverse categorie:

- **Documenti**: PDF, DOC, DOCX, RTF, ODT, XPS, EPUB, HTML  
- **Fogli di calcolo**: XLS, XLSX, XLSM, XLSB, ODS, CSV, TSV  
- **Presentazioni**: PPT, PPTX, PPS, PPSX, ODP  
- **Immagini**: JPG, PNG, BMP, GIF, TIFF, SVG  
- **Diagrammi**: VSDX, VSDM, VSSX, VSTX, VDX, VSX, VTX  
- **Archivi**: ZIP, TAR, 7Z  
- **E molti altri**

## Domande frequenti

**D: Posso usare l'API in un prodotto commerciale?**  
R: Sì, con una licenza GroupDocs valida. È disponibile una prova gratuita per la valutazione.

**D: L'API supporta PDF protetti da password?**  
R: Assolutamente. Puoi aprire, modificare e ri‑proteggere PDF crittografati usando le stesse chiamate API.

**D: Quali versioni di .NET e Java sono compatibili?**  
R: .NET Standard 2.0, .NET Framework 2.0+, .NET Core 2.0+, Mono 1.2+; Java 7, 8 e 10+ sono pienamente supportati.

**D: Come gestisce l'API file molto grandi?**  
R: Trasmette i dati in streaming e utilizza algoritmi a basso consumo di memoria, consentendo di processare documenti multi‑gigabyte senza esaurire le risorse di sistema.

**D: È disponibile il supporto integrato per OCR o estrazione di testo?**  
R: Sebbene l'API di fusione principale si concentri su operazioni strutturali, è possibile combinarla con GroupDocs.Parser per estrazione avanzata di testo e necessità OCR.

**D: Come posso iniziare rapidamente?**  
R: Installa il pacchetto NuGet (`GroupDocs.Merger`) per .NET o aggiungi la dipendenza Maven per Java, quindi segui il tutorial “Caricamento documenti” per caricare il tuo primo file.

**D: Posso unire diversi tipi di file in un unico PDF?**  
R: Sì – l'API può unire PDF, Word, Excel, immagini e molti altri formati in un unico PDF di output.
