# GroupDocs.Merger 문서 병합 API – 병합 및 분할에 대한 완전 가이드

**GroupDocs.Merger 문서 병합 API**는 .NET 또는 Java 애플리케이션에서 직접 다양한 문서 유형을 결합, 분할 및 조작할 수 있는 빠르고 크로스‑플랫폼 방식을 제공합니다. 여러 PDF를 하나의 보고서로 병합하거나, 큰 계약서를 개별 페이지로 분할하거나, 프레젠테이션의 슬라이드를 재정렬해야 할 경우에도 이 API는 몇 줄의 코드만으로 처리합니다.

## 빠른 답변
- **API는 무엇을 하나요?** 50개 이상의 형식에 걸쳐 문서를 병합, 분할, 재정렬 및 보호합니다.  
- **지원되는 플랫폼은 무엇인가요?** .NET (Standard, Framework, Core, Mono) 및 Java (J2SE 7‑10).  
- **외부 소프트웨어가 필요합니까?** 필요 없습니다—Microsoft Office 또는 Adobe 의존성이 없습니다.  
- **문서를 보호할 수 있나요?** 예, 비밀번호와 권한을 추가, 제거 또는 업데이트할 수 있습니다.  
- **파일 크기에 제한이 있나요?** API는 대용량 파일 및 배치 작업에 최적화되어 있습니다.  

## GroupDocs.Merger 문서 병합 API란?
파일을 로드하고 적절한 병합 또는 분할 메서드를 호출하면 됩니다 – 이것이 GroupDocs.Merger 문서 병합 API의 핵심 워크플로우입니다. PDF, Office 문서, 이미지, 압축 파일 등 다양한 형식을 처리하면서 레이아웃, 메타데이터 및 보안 설정을 보존하는 단일하고 일관된 인터페이스를 제공합니다.

GroupDocs.Merger 문서 병합 API는 개발자 중심의 라이브러리로, 여러 문서 형식을 다루는 복잡성을 추상화합니다. 파일을 프로그래밍 방식으로 병합하고, 페이지 또는 범위별로 분할하며, 고급 페이지 작업을 적용할 수 있으며, 원본 레이아웃과 메타데이터를 보존합니다.

## 왜 GroupDocs.Merger 문서 병합 API를 선택해야 하나요?
크로스‑플랫폼 일관성, 광범위한 형식 지원, 외부 종속성 없음, 높은 성능 및 내장 보안을 하나의 패키지에서 제공합니다. API는 데이터를 스트리밍하므로 멀티‑기가바이트 파일도 낮은 메모리 사용량으로 처리되어 서버‑사이드 배치 작업에 이상적입니다.

## 여러 플랫폼에서 문서 관리 방식을 혁신하세요
GroupDocs.Merger는 문서 조작을 위한 강력한 크로스‑플랫폼 솔루션을 제공하여 개발자가 애플리케이션에서 파일을 다루는 방식을 간소화합니다. 우리의 포괄적인 API를 사용하면 여러 문서를 하나로 병합하고, 문서를 작은 구성 요소로 분할하며, 페이지를 재정렬하고, 보안 옵션을 적용하는 등 다양한 작업을 최소한의 코드와 최대 효율성으로 수행할 수 있습니다.

.NET 또는 Java 환경에서 개발하든, GroupDocs.Merger는 PDF, Office 문서, 이미지 등 50개 이상의 인기 파일 형식과 원활하게 작동하는 일관되고 고성능의 문서 처리 기능을 제공합니다.

## 주요 기능 및 역량
- **포괄적인 문서 병합** – 여러 소스의 전체 문서 또는 특정 페이지를 하나의 일관된 파일로 결합합니다.  
- **크로스‑포맷 지원** – 서로 다른 파일 형식을 하나의 문서로 병합합니다 (예: DOC, XLSX 및 이미지를 단일 PDF로).  
- **스마트 문서 분할** – 페이지 번호, 범위별로 문서를 나누거나 특정 페이지를 별도 파일로 추출합니다.  
- **고급 페이지 작업** – 페이지를 이동, 제거, 회전, 교체 및 추출하며 정밀하게 제어합니다.  
- **보안 관리** – 문서 비밀번호와 권한을 추가, 제거 또는 업데이트합니다.  
- **OLE 객체 지원** – Word, Excel, PowerPoint 및 Visio 파일에 문서를 OLE 객체로 삽입합니다.  
- **외부 종속성 없음** – Microsoft Office 또는 Adobe 소프트웨어 없이 문서를 처리합니다.  
- **고성능** – 대용량 문서 및 배치 작업을 효율적으로 처리하도록 최적화되었습니다.

## 지원되는 파일 형식
GroupDocs.Merger는 여러 카테고리에 걸쳐 50개 이상의 파일 형식을 지원합니다:

- **문서**: PDF, DOC, DOCX, RTF, ODT, XPS, EPUB, HTML  
- **스프레드시트**: XLS, XLSX, XLSM, XLSB, ODS, CSV, TSV  
- **프레젠테이션**: PPT, PPTX, PPS, PPSX, ODP  
- **이미지**: JPG, PNG, BMP, GIF, TIFF, SVG  
- **다이어그램**: VSDX, VSDM, VSSX, VSTX, VDX, VSX, VTX  
- **압축 파일**: ZIP, TAR, 7Z  
- **그 외 다수**

## 일반적인 사용 사례 및 이점
- **자동 보고서 생성:** 데이터 기반 PDF와 Excel 시트를 하나의 보고서로 병합하여 배포합니다.

- **콘텐츠 마이그레이션:** 여러 형식의 레거시 문서를 변환 및 병합하여 표준화된 PDF 아카이브로 만듭니다.

## 자주 묻는 질문
**Q: API를 상용 제품에 사용할 수 있나요?**  
A: 예, 유효한 GroupDocs 라이선스가 있으면 가능합니다. 평가용 무료 체험판을 제공합니다.

**Q: API가 비밀번호로 보호된 PDF를 지원하나요?**  
A: 물론입니다. 동일한 API 호출을 사용해 암호화된 PDF를 열고, 수정하고, 다시 보호할 수 있습니다.

**Q: 호환되는 .NET 및 Java 버전은 무엇인가요?**  
A: .NET Standard 2.0, .NET Framework 2.0+, .NET Core 2.0+, Mono 1.2+; Java 7, 8, 및 10+을 완전히 지원합니다.

**Q: API가 매우 큰 파일을 어떻게 처리하나요?**  
A: 데이터를 스트리밍하고 메모리 효율적인 알고리즘을 사용하여 시스템 리소스를 고갈시키지 않고 멀티‑기가바이트 문서를 처리할 수 있습니다.

**Q: OCR 또는 텍스트 추출에 대한 내장 지원이 있나요?**  
A: 핵심 병합 API는 구조적 작업에 초점을 맞추지만, 고급 텍스트 추출 및 OCR이 필요할 경우 GroupDocs.Parser와 결합하여 사용할 수 있습니다.

**Q: 어떻게 빠르게 시작할 수 있나요?**  
A: .NET용 NuGet 패키지(`GroupDocs.Merger`)를 설치하거나 Java용 Maven 의존성을 추가한 뒤, “문서 로드” 튜토리얼을 따라 첫 파일을 로드합니다.

**Q: 서로 다른 파일 유형을 하나의 PDF로 병합할 수 있나요?**  
A: 예 – API는 PDF, Word, Excel, 이미지 및 기타 많은 형식을 단일 PDF 출력으로 병합할 수 있습니다.
