# GroupDocs.Merger API scalania dokumentów – kompletny przewodnik po scalaniu i dzieleniu

The **GroupDocs.Merger document merging API** gives you a fast, cross‑platform way to combine, split, and manipulate a wide range of document types directly from your .NET or Java applications. Whether you need to merge several PDFs into a single report, split a large contract into individual pages, or reorder slides in a presentation, this API handles it with just a few lines of code.

## Szybkie odpowiedzi
- **Co robi API?** Łączy, dzieli, zmienia kolejność i zabezpiecza dokumenty w ponad 50 formatach.  
- **Jakie platformy są obsługiwane?** .NET (Standard, Framework, Core, Mono) i Java (J2SE 7‑10).  
- **Czy potrzebne jest oprogramowanie zewnętrzne?** Nie — nie wymaga Microsoft Office ani zależności Adobe.  
- **Czy mogę zabezpieczyć dokumenty?** Tak, możesz dodawać, usuwać lub aktualizować hasła i uprawnienia.  
- **Czy istnieje limit rozmiaru pliku?** API jest zoptymalizowane pod kątem dużych plików i operacji wsadowych.  

## Czym jest GroupDocs.Merger API scalania dokumentów?

Load your files and call the appropriate merge or split methods – that’s the core workflow of the GroupDocs.Merger document merging API. It provides a single, consistent interface for handling PDFs, Office documents, images, archives, and more, while preserving layout, metadata, and security settings.

Załaduj swoje pliki i wywołaj odpowiednie metody scalania lub dzielenia – to podstawowy przepływ pracy GroupDocs.Merger API scalania dokumentów. Zapewnia ono jednolite, spójne interfejsy do obsługi PDF‑ów, dokumentów Office, obrazów, archiwów i innych, zachowując układ, metadane i ustawienia zabezpieczeń.

The GroupDocs.Merger document merging API is a developer‑focused library that abstracts the complexity of handling multiple document formats. It lets you programmatically merge files, split them by pages or ranges, and apply advanced page operations—all while preserving the original layout and metadata.

GroupDocs.Merger API scalania dokumentów to biblioteka skierowana do programistów, która ukrywa złożoność obsługi wielu formatów dokumentów. Umożliwia programowe scalanie plików, ich dzielenie według stron lub zakresów oraz stosowanie zaawansowanych operacji na stronach — wszystko przy zachowaniu oryginalnego układu i metadanych.

## Dlaczego warto wybrać GroupDocs.Merger API scalania dokumentów?

You get cross‑platform consistency, broad format support, no external dependencies, high performance, and built‑in security—all in one package. The API streams data, so even multi‑gigabyte files are processed with a low memory footprint, making it ideal for server‑side batch jobs.

Otrzymujesz spójność międzyplatformową, szerokie wsparcie formatów, brak zależności zewnętrznych, wysoką wydajność oraz wbudowane zabezpieczenia — wszystko w jednym pakiecie. API strumieniuje dane, więc nawet pliki o rozmiarze kilku gigabajtów są przetwarzane przy niskim zużyciu pamięci, co czyni je idealnym do zadań wsadowych po stronie serwera.

## Zmieniaj sposób zarządzania dokumentami na wielu platformach

GroupDocs.Merger zapewnia potężne, wieloplatformowe rozwiązanie do manipulacji dokumentami, które usprawnia sposób, w jaki programiści pracują z plikami w swoich aplikacjach. Nasze kompleksowe API umożliwia scalanie wielu dokumentów w jeden, dzielenie dokumentów na mniejsze części, zmianę kolejności stron, stosowanie opcji zabezpieczeń i wiele więcej — wszystko przy minimalnej ilości kodu i maksymalnej wydajności.

Niezależnie od tego, czy tworzysz aplikacje w środowiskach .NET czy Java, GroupDocs.Merger dostarcza spójne, wysokowydajne możliwości przetwarzania dokumentów, które działają bezproblemowo z ponad 50 popularnymi formatami plików, w tym PDF, dokumentami Office, obrazami i innymi.

## Kluczowe funkcje i możliwości
- **Comprehensive document merging** – Łącz całe dokumenty lub wybrane strony z wielu źródeł w jeden spójny plik.  
- **Cross‑format support** – Scalaj różne formaty plików w jeden dokument (np. DOC, XLSX i obrazy w pojedynczy PDF).  
- **Smart document splitting** – Dziel dokumenty według numerów stron, zakresów lub wyodrębniaj konkretne strony jako oddzielne pliki.  
- **Advanced page operations** – Przenoś, usuwaj, obracaj, zamieniaj i wyodrębniaj strony z precyzyjną kontrolą.  
- **Security management** – Dodawaj, usuwaj lub aktualizuj hasła i uprawnienia dokumentów.  
- **OLE object support** – Wstawiaj dokumenty jako obiekty OLE w plikach Word, Excel, PowerPoint i Visio.  
- **No external dependencies** – Przetwarzaj dokumenty bez wymogu posiadania Microsoft Office lub oprogramowania Adobe.  
- **High performance** – Zoptymalizowane pod kątem efektywnego przetwarzania dużych dokumentów i operacji wsadowych.

## Obsługiwane formaty plików
GroupDocs.Merger works with over 50 file formats across multiple categories:

- **Documents**: PDF, DOC, DOCX, RTF, ODT, XPS, EPUB, HTML  
- **Spreadsheets**: XLS, XLSX, XLSM, XLSB, ODS, CSV, TSV  
- **Presentations**: PPT, PPTX, PPS, PPSX, ODP  
- **Images**: JPG, PNG, BMP, GIF, TIFF, SVG  
- **Diagrams**: VSDX, VSDM, VSSX, VSTX, VDX, VSX, VTX  
- **Archives**: ZIP, TAR, 7Z  
- **And many more**

**Q: Czy mogę używać API w produkcie komercyjnym?**

A: .NET Standard 2.0, .NET Framework 2.0+, .NET Core 2.0+, Mono 1.2+; Java 7, 8 i 10+ są w pełni obsługiwane.

**Q: Jak API radzi sobie z bardzo dużymi plikami?**

**Q: Czy istnieje wbudowane wsparcie dla OCR lub wyodrębniania tekstu?**
