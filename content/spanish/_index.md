# GroupDocs.Merger API de fusión de documentos – guía completa para combinar y dividir

La **GroupDocs.Merger document merging API** le brinda una forma rápida y multiplataforma de combinar, dividir y manipular una amplia gama de tipos de documentos directamente desde sus aplicaciones .NET o Java. Ya sea que necesite combinar varios PDFs en un solo informe, dividir un contrato grande en páginas individuales, o reordenar diapositivas en una presentación, esta API lo maneja con solo unas pocas líneas de código.

## Respuestas rápidas
- **¿Qué hace la API?** Fusiona, divide, reordena y protege documentos en más de 50 formatos.  
- **¿Qué plataformas son compatibles?** .NET (Standard, Framework, Core, Mono) y Java (J2SE 7‑10).  
- **¿Necesito software externo?** No—no hay dependencias de Microsoft Office ni Adobe.  
- **¿Puedo proteger documentos?** Sí, puede agregar, eliminar o actualizar contraseñas y permisos.  
- **¿Hay un límite de tamaño de archivo?** La API está optimizada para archivos grandes y operaciones por lotes.  

## Qué es la API de fusión de documentos GroupDocs.Merger
Cargue sus archivos y llame a los métodos de fusión o división apropiados; ese es el flujo de trabajo principal de la API de fusión de documentos GroupDocs.Merger. Proporciona una única interfaz coherente para manejar PDFs, documentos de Office, imágenes, archivos comprimidos y más, mientras preserva el diseño, los metadatos y la configuración de seguridad.

La API de fusión de documentos GroupDocs.Merger es una biblioteca centrada en el desarrollador que abstrae la complejidad de manejar múltiples formatos de documentos. Le permite fusionar archivos programáticamente, dividirlos por páginas o rangos, y aplicar operaciones avanzadas de página, todo mientras preserva el diseño y los metadatos originales.

## Por qué elegir la API de fusión de documentos GroupDocs.Merger
Obtiene consistencia multiplataforma, amplio soporte de formatos, sin dependencias externas, alto rendimiento y seguridad incorporada, todo en un solo paquete. La API transmite datos, por lo que incluso archivos de varios gigabytes se procesan con una huella de memoria baja, lo que la hace ideal para trabajos por lotes en el servidor.

## Transforme la forma en que gestiona documentos en múltiples plataformas
GroupDocs.Merger ofrece una solución poderosa y multiplataforma para la manipulación de documentos que optimiza la forma en que los desarrolladores trabajan con archivos en sus aplicaciones. Nuestra API integral le permite combinar varios documentos en uno, dividir documentos en componentes más pequeños, reordenar páginas, aplicar opciones de seguridad y mucho más, todo con código mínimo y máxima eficiencia.

Ya sea que esté desarrollando en entornos .NET o Java, GroupDocs.Merger ofrece capacidades de procesamiento de documentos consistentes y de alto rendimiento que funcionan sin problemas con más de 50 formatos de archivo populares, incluidos PDF, documentos de Office, imágenes y más.

## Características clave y capacidades
- **Fusión integral de documentos** – Combine documentos completos o páginas específicas de múltiples fuentes en un único archivo coherente.  
- **Soporte multiplataforma de formatos** – Fusiona diferentes formatos de archivo en un documento unificado (p. ej., DOC, XLSX e imágenes en un solo PDF).  
- **División inteligente de documentos** – Divida documentos por números de página, rangos, o extraiga páginas específicas como archivos separados.  
- **Operaciones avanzadas de página** – Mueva, elimine, rote, intercambie y extraiga páginas con control preciso.  
- **Gestión de seguridad** – Agregue, elimine o actualice contraseñas y permisos de documentos.  
- **Soporte de objetos OLE** – Inserte documentos como objetos OLE dentro de archivos Word, Excel, PowerPoint y Visio.  
- **Sin dependencias externas** – Procese documentos sin requerir software de Microsoft Office o Adobe.  
- **Alto rendimiento** – Optimizado para procesar documentos grandes y operaciones por lotes de manera eficiente.

## Formatos de archivo compatibles
GroupDocs.Merger funciona con más de 50 formatos de archivo en múltiples categorías:

- **Documentos**: PDF, DOC, DOCX, RTF, ODT, XPS, EPUB, HTML  
- **Hojas de cálculo**: XLS, XLSX, XLSM, XLSB, ODS, CSV, TSV  
- **Presentaciones**: PPT, PPTX, PPS, PPSX, ODP  
- **Imágenes**: JPG, PNG, BMP, GIF, TIFF, SVG  
- **Diagramas**: VSDX, VSDM, VSSX, VSTX, VDX, VSX, VTX  
- **Archivos comprimidos**: ZIP, TAR, 7Z  
- **Y muchos más**

## Preguntas frecuentes
**P: ¿Puedo usar la API en un producto comercial?**  
R: Sí, con una licencia válida de GroupDocs. Hay una prueba gratuita disponible para evaluación.

**P: ¿La API admite PDFs protegidos con contraseña?**  
R: Absolutamente. Puede abrir, modificar y volver a asegurar PDFs encriptados usando las mismas llamadas de API.

**P: ¿Qué versiones de .NET y Java son compatibles?**  
R: .NET Standard 2.0, .NET Framework 2.0+, .NET Core 2.0+, Mono 1.2+; Java 7, 8 y 10+ son totalmente compatibles.

**P: ¿Cómo maneja la API archivos muy grandes?**  
R: Transmite datos y usa algoritmos eficientes en memoria, lo que le permite procesar documentos de varios gigabytes sin agotar los recursos del sistema.

**P: ¿Hay soporte incorporado para OCR o extracción de texto?**  
R: Aunque la API central de fusión se centra en operaciones estructurales, puede combinarla con GroupDocs.Parser para extracción avanzada de texto y necesidades de OCR.

**P: ¿Cómo puedo comenzar rápidamente?**  
R: Instale el paquete NuGet (`GroupDocs.Merger`) para .NET o agregue la dependencia Maven para Java, luego siga el tutorial “Carga de documentos” para cargar su primer archivo.

**P: ¿Puedo combinar diferentes tipos de archivo en un PDF?**  
R: Sí, la API puede combinar PDFs, Word, Excel, imágenes y muchos otros formatos en una única salida PDF.
