# API hợp nhất tài liệu GroupDocs.Merger – hướng dẫn đầy đủ về hợp nhất & tách

**GroupDocs.Merger document merging API** cung cấp cho bạn một cách nhanh chóng, đa nền tảng để kết hợp, tách và thao tác với nhiều loại tài liệu trực tiếp từ các ứng dụng .NET hoặc Java của bạn. Cho dù bạn cần hợp nhất một vài tệp PDF thành một báo cáo duy nhất, tách một hợp đồng lớn thành các trang riêng lẻ, hoặc sắp xếp lại các slide trong một bản trình chiếu, API này chỉ cần vài dòng mã để thực hiện.

## Câu trả lời nhanh
- **API này làm gì?** Nó hợp nhất, tách, sắp xếp lại và bảo mật tài liệu trên hơn 50 định dạng.  
- **Các nền tảng nào được hỗ trợ?** .NET (Standard, Framework, Core, Mono) và Java (J2SE 7‑10).  
- **Tôi có cần phần mềm bên ngoài không?** Không—không cần Microsoft Office hay Adobe.  
- **Tôi có thể bảo vệ tài liệu không?** Có, bạn có thể thêm, xóa hoặc cập nhật mật khẩu và quyền truy cập.  
- **Có giới hạn kích thước tệp không?** API được tối ưu cho tệp lớn và các thao tác batch.  

## GroupDocs.Merger document merging API là gì?
Tải các tệp của bạn và gọi các phương thức hợp nhất hoặc tách phù hợp – đó là quy trình làm việc cốt lõi của GroupDocs.Merger API. Nó cung cấp một giao diện duy nhất, nhất quán để xử lý PDF, tài liệu Office, hình ảnh, tệp lưu trữ và hơn thế nữa, đồng thời giữ nguyên bố cục, siêu dữ liệu và cài đặt bảo mật.

GroupDocs.Merger document merging API là một thư viện hướng tới nhà phát triển, trừu tượng hoá sự phức tạp khi xử lý nhiều định dạng tài liệu. Nó cho phép bạn lập trình hợp nhất tệp, tách chúng theo trang hoặc phạm vi, và áp dụng các thao tác trang nâng cao—tất cả trong khi giữ nguyên bố cục và siêu dữ liệu gốc.

## Tại sao nên chọn GroupDocs.Merger document merging API?
Bạn nhận được tính nhất quán đa nền tảng, hỗ trợ rộng rãi các định dạng, không phụ thuộc vào phần mềm bên ngoài, hiệu năng cao và bảo mật tích hợp—tất cả trong một gói. API truyền dữ liệu dạng stream, vì vậy ngay cả các tệp đa gigabyte cũng được xử lý với mức tiêu thụ bộ nhớ thấp, phù hợp cho các công việc batch phía server.

## Biến đổi cách bạn quản lý tài liệu trên nhiều nền tảng
GroupDocs.Merger cung cấp một giải pháp mạnh mẽ, đa nền tảng cho việc thao tác tài liệu, giúp đơn giản hoá quy trình làm việc của các nhà phát triển với tệp trong ứng dụng. API toàn diện của chúng tôi cho phép bạn hợp nhất nhiều tài liệu thành một, tách tài liệu thành các thành phần nhỏ hơn, sắp xếp lại các trang, áp dụng các tùy chọn bảo mật và nhiều hơn nữa—tất cả với ít mã và hiệu quả tối đa.

Cho dù bạn đang phát triển trong môi trường .NET hay Java, GroupDocs.Merger mang lại khả năng xử lý tài liệu nhất quán, hiệu năng cao, hoạt động liền mạch với hơn 50 định dạng tệp phổ biến bao gồm PDF, tài liệu Office, hình ảnh và hơn thế nữa.

## Các tính năng chính & khả năng
- **Hợp nhất tài liệu toàn diện** – Kết hợp toàn bộ tài liệu hoặc các trang cụ thể từ nhiều nguồn thành một tệp duy nhất.  
- **Hỗ trợ đa định dạng** – Hợp nhất các định dạng tệp khác nhau thành một tài liệu thống nhất (ví dụ: DOC, XLSX và hình ảnh thành một PDF duy nhất).  
- **Tách tài liệu thông minh** – Chia tài liệu theo số trang, phạm vi, hoặc trích xuất các trang cụ thể thành các tệp riêng.  
- **Các thao tác trang nâng cao** – Di chuyển, xóa, xoay, hoán đổi và trích xuất các trang với kiểm soát chính xác.  
- **Quản lý bảo mật** – Thêm, xóa hoặc cập nhật mật khẩu và quyền truy cập của tài liệu.  
- **Hỗ trợ đối tượng OLE** – Chèn tài liệu dưới dạng đối tượng OLE trong các tệp Word, Excel, PowerPoint và Visio.  
- **Không phụ thuộc vào phần mềm bên ngoài** – Xử lý tài liệu mà không cần Microsoft Office hay phần mềm Adobe.  
- **Hiệu năng cao** – Tối ưu cho việc xử lý tài liệu lớn và các thao tác batch một cách hiệu quả.  

## Định dạng tệp được hỗ trợ
GroupDocs.Merger làm việc với hơn 50 định dạng tệp trên nhiều danh mục:

- **Tài liệu**: PDF, DOC, DOCX, RTF, ODT, XPS, EPUB, HTML  
- **Bảng tính**: XLS, XLSX, XLSM, XLSB, ODS, CSV, TSV  
- **Bản trình chiếu**: PPT, PPTX, PPS, PPSX, ODP  
- **Hình ảnh**: JPG, PNG, BMP, GIF, TIFF, SVG  
- **Sơ đồ**: VSDX, VSDM, VSSX, VSTX, VDX, VSX, VTX  
- **Lưu trữ**: ZIP, TAR, 7Z  
- **Và nhiều hơn nữa**

## Câu hỏi thường gặp

**Q: Tôi có thể sử dụng API trong sản phẩm thương mại không?**  
A: Có, với giấy phép GroupDocs hợp lệ. Bạn có thể dùng bản dùng thử miễn phí để đánh giá.

**Q: API có hỗ trợ PDF được bảo vệ bằng mật khẩu không?**  
A: Hoàn toàn có. Bạn có thể mở, sửa đổi và bảo mật lại các PDF đã mã hoá bằng cùng một bộ lệnh API.

**Q: Các phiên bản .NET và Java nào tương thích?**  
A: .NET Standard 2.0, .NET Framework 2.0+, .NET Core 2.0+, Mono 1.2+; Java 7, 8 và 10+ đều được hỗ trợ đầy đủ.

**Q: API xử lý các tệp rất lớn như thế nào?**  
A: Nó truyền dữ liệu dạng stream và sử dụng các thuật toán tiết kiệm bộ nhớ, cho phép bạn xử lý các tài liệu đa gigabyte mà không làm cạn kiệt tài nguyên hệ thống.

**Q: Có hỗ trợ OCR hoặc trích xuất văn bản tích hợp không?**  
A: Mặc dù API hợp nhất cốt lõi tập trung vào các thao tác cấu trúc, bạn có thể kết hợp nó với GroupDocs.Parser để thực hiện trích xuất văn bản và OCR nâng cao.

**Q: Làm sao để bắt đầu nhanh chóng?**  
A: Cài đặt gói NuGet (`GroupDocs.Merger`) cho .NET hoặc thêm phụ thuộc Maven cho Java, sau đó làm theo hướng dẫn “Tải Tài liệu” để tải tệp đầu tiên của bạn.

**Q: Tôi có thể hợp nhất các loại tệp khác nhau thành một PDF không?**  
A: Có – API có thể hợp nhất PDF, Word, Excel, hình ảnh và nhiều định dạng khác thành một file PDF duy nhất.
